# Gadget

노션 `/embed` 블록에 하나씩 넣어 쓰는 미니멀 위젯 모음입니다. 빌드 과정 없이 정적 파일만으로 동작합니다.

- 배경 투명, 글자색은 OS/브라우저 테마(라이트·다크)를 따름
- 세리프 서체(EB Garamond + Noto Serif KR), 포인트 색 하나

| 모듈 | 경로 | 옵션 |
|---|---|---|
| 시계 · 날짜 · 날씨 | `clock/` | 배치: `top`·`left`·`center`·`right`·`bottom` = 요소 목록 (예: `left=analog&center=digital,date&right=weather`, 한 칸에 여럿이면 위아래로 쌓임. 왼쪽·오른쪽 칸은 전체 높이를 차지하고, 아날로그와 디지털·날짜가 같은 칸이면 글자가 시계 안쪽에 들어감) · 크기: `asize`, `dsize`, `datesize`, `wsize` (기본 1), `gap=0.15` · `hand=0`, `seconds=1`, `hour12=1`, `blink=0`, `lang=en`, `tz` · 날씨를 넣으면 `city`, `name`, `tomorrow`, `wdir=auto\|row\|column`(자동: 왼쪽·오른쪽 칸을 혼자 차지하면 세로)도 사용 |
| 날씨 (단독) | `weather/` | `city=서울` (필수), `name=표시 이름`, `tomorrow=0`, 또는 `lat`+`lon` — 설정 화면에서는 시계 위젯에 날씨만 켜서 쓰면 됨 |
| 포모도로 | `pomodoro/` | `min=90`, `layout=auto\|ring\|bar`, `tsize=1`(막대 크기, 1 = 높이 꽉 채움), `vol=0.6`, `id=default` |

공통 옵션: `theme=auto|light|dark`, `accent=c8553d` (# 없는 hex).
루트의 `index.html`(설정 화면)에서 포인트 색·테마를 한 번 정하면 모든 주소에 적용되고, 시계 배치는 드래그 앤 드롭으로 정할 수 있습니다. 설정은 브라우저에 저장됩니다.
모든 위젯은 내용물을 임베드 크기에 꽉 맞춰 그리므로, 노션에서 블록 크기만 조절하면 됩니다. 이전 `date/` 주소와 이전 시계 옵션(`analog`, `pos` 등)도 계속 동작합니다. 

## 배포 (GitHub Pages)

1. 저장소 Settings → Pages → Source: *Deploy from a branch* → 이 브랜치, `/ (root)` 선택
2. `https://<사용자>.github.io/Gadget/` 가 열리면 각 위젯 주소를 노션에서 `/embed`로 붙여 넣기

## 동작 메모

**날씨** — 위치는 저장소에 저장하지 않고 임베드 주소의 `city`로만 받습니다. 도시 이름으로 좌표를 찾고(못 찾으면 영문 이름으로 시도해 보세요) [Open-Meteo](https://open-meteo.com/) (키 불필요)에서 오늘의 날씨 코드·최고/최저 기온·최대 강수 확률을 가져옵니다. 30분마다, 그리고 다시 화면에 보일 때 오래됐으면 갱신합니다.

**포모도로**
- 남은 시간이 아니라 *종료 시각*을 저장하므로 창을 최소화하거나 새로고침해도 시간이 어긋나지 않습니다.
- 알림 소리는 시작할 때 Web Audio 시계에 미리 예약합니다. 탭이 숨겨져 타이머가 느려져도 소리는 제시간에 납니다.
- 시간은 대기 상태에서 숫자를 클릭해 분 단위로 바꿀 수 있습니다.
- 세로 200px 이상이면 원형, 그보다 낮으면 막대 형태로 바뀝니다.
- 실행 중에 페이지를 새로 열면 브라우저 정책상 소리를 바로 낼 수 없어 "알림 소리 켜기"가 표시됩니다. 위젯을 한 번 클릭하면 됩니다.
- 여러 개를 넣을 때는 `id`를 다르게 주면 각자 따로 저장됩니다.

알림이 울리려면:
- 노션 탭에서 위젯이 있는 페이지를 띄워 두세요. 같은 탭에서 다른 페이지로 이동하면 위젯이 사라집니다.
- 크롬 *메모리 절약 모드* / 엣지 *절전 탭*이 오래 쉬는 탭을 잠재울 수 있습니다. `notion.so`를 "항상 활성 상태로 유지할 사이트"에 추가하세요.

## 문제 해결

- **다크 모드에서 배경이 불투명하게 보임**: 위젯과 노션의 `color-scheme`이 다르면 브라우저가 배경을 칠합니다. 주소에 `&scheme=dark`(또는 `light`)를 붙여 보세요.
- **노션 테마와 색이 다름**: 위젯은 노션 설정이 아니라 OS 테마를 따릅니다. 노션 테마를 "시스템 설정 사용"으로 두거나 `theme=dark`로 고정하세요.
